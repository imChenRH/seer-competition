## 二、方案成果展示【必须包含】

### 2.1 命题场景描述、问题描述及痛点说明

**业务场景**：停靠在仓储月台的集装箱需要卸货——叉车进入箱内，叉取带栈板的整托货物，转运到指定点位或对接后端传送带。

**【插入图 A：`fig-A-场景概念图.png`，标注：AI 辅助概念示意图，非运行截图】**

**核心痛点**：

1. **司机供给端**：资深叉车司机缺口逐年收窄；岗位经验门槛高、作业环境差、工作枯燥，年轻人不愿入行。
2. **任务不确定性强**：箱内货物摆放不规律、栈板规格不一、存在位移和遮挡，传统规则自动化难以适配。
3. **现场代价直接**：对位失败时只能等待有经验的司机处置，拖低卸货节拍；人工操作和状态记录分离，出了问题难以复现和定位。
4. **智能升级的误区**：如果只追求“模型能跑 demo”，没有任务编排、安全兜底和可追溯证据，工业现场“不敢用”。

**一句话判断**：工业要的不是最聪明的模型，而是**出了事能查、上线前能验、危险时能停**的系统。

---

### 2.2 方案优势 / 创新点

1. **层次化 VLA：泛化与可控兼得**。VLA 只输出“技能选择 + 目标参数”，不直接输出关节/底盘动作；经典规控负责执行与安全。Fast-WAM 已在官方 LIBERO task 8 真实验证：固定初态 5/5，77–84 步完成，全部 7D 动作来自已绑定 revision 与 SHA-256 的 checkpoint。
2. **AgentOS 全飞书落地**。Aily 决策 + 5 张多维表格 + 单实例桥接，覆盖任务分解、技能库、Fallback、状态记忆、审计回写；现场任务 `T-DEMO-20260813-001` 只启动一次 runner，审计事件 0–19 连续。
3. **单一事实源证据链**。所有页面数字由 `events.jsonl` 推导；Manifest SHA-256 封存视频/场景/回执；输入与证据不一致时网页 fail-closed，不伪造执行。
4. **工业级容错与安全**。九技能链 + FB-F01/FB-F02/FB-F07 恢复策略；`2.5D_OBB_SAT_SWEEP_V4` 三场景共 3,029,546 次候选对检查，禁碰/穿透/接触违规均为 0；安全停车同时验证停稳和低速。
5. **影子模式渐进接管**。阶段 1 规控执行 + Fast-WAM 影子建议；阶段 2 数据达标后有条件接管；阶段 3 端侧算力升级后全端部署。每一步都有退出条件，避免“一次性黑箱切换”。

**Before / After（模板双栏）**：

| Before（传统人工/纯规则） | After（AgentOS + 层次化 VLA + 证据链） |
|---|---|
| 依赖老师傅经验，熟手缺口逐年扩大 | 自然语言任务 → Aily 结构化任务图 → 技能序列 |
| 对位失败只能等人来处理 | FB-F01 自动横向修正后重试 |
| 故障只能看结果，过程不可追溯 | 每条技能/Fallback 写入连续审计事件 |
| 汇报数字靠手工表，口径不一 | 页面数字全部由 JSONL 派生，Manifest 哈希封存 |
| 新场景重新编程，周期以天/周计 | 技能库重组 + 影子模式，目标小时级切换（设计目标） |

### 2.3 具体方案说明（突出 AI 能力）

#### 2.3.1 总体架构：四层可验证闭环

**【插入图 C：`fig-C-四层架构总览.png`】**

- **交互理解层（Aily）**：自然语言 → 结构化任务图（做什么、在哪、优先级、时效）。
- **AgentOS 编排层**：任务图 → 九技能序列；技能有前置/后置条件；异常进入 Fallback；状态写审计。
- **VLA / 执行层**：技能 + 观测 → 目标参数 → “生成 → 验证 → 执行”流水线。
- **M4 / 规控与安全层**：轨迹执行、USD 物理挂接、碰撞守卫、安全停车。

关键原则：**VLA 做软决策，规控做硬执行，AgentOS 做中间编排**。每层都有平台、输入输出和证据，故障可定位到层。

#### 2.3.2 大脑：AgentOS 的九技能链与 Fallback

**【插入图 D：`fig-D-九技能链与Fallback状态机.png`】**

- normal：进箱导航 → 精确对位 → 栈板识别 → 货叉插入 → 门架起升 → 货叉倾斜 → 月台区导航 → 传送带对接 → 栈板放置；实测 20 条事件、9/9 技能、66.25 s、`COMPLETED`。
- recovery：首次对位失败 → `FB-F01` 横向修正 → 重试完成；24 条事件、77.25 s、`COMPLETED`。
- intervention：遮挡导致连续三次识别失败 → `FB-F02` 切换观察位姿 → 仍失败 → `FB-F07` 箱外安全停车（|v|≤0.01 m/s）；18 条事件、36.0 s、`HUMAN_REQUIRED`。

**AI 深度体现在核心链路，不是边角**：自然语言任务、技能选择、异常恢复、安全停车、终态判定由同一事件契约串起来，页面只读回放。

#### 2.3.3 小脑：层次化 VLA 与 Fast-WAM 真实运行

**【插入图 E：`fig-E-FastWAM概念插画.png`】**

- 使用 `lerobot/fastwam_libero_uncond_2cam224`，revision `53983e1249b4eb4d89ab42b40b8678a882d331ad`，运行前验证 config/weights SHA-256。
- 官方 LIBERO `libero_goal` task 8：把黑色碗放入盘子；不改 BDDL、不改资产、不改成功谓词。
- 五个固定初态在 300 步预算内全部通过 `env.check_success()`，实际执行 84/79/77/79/80 步，策略调用 9/8/8/8/8 次。
- 五次 attempt 的视频/动作/状态逐组交叉验证，并纳入 Manifest 哈希。
- **边界**：5/5 只描述随附固定初态，不是通用成功率；Fast-WAM 尚未控制叉车；论文 190 ms 是论文指标，不写成本机实测。

#### 2.3.4 安全与可验证：防穿模守卫 + 单一事实源

**【插入图 F：`fig-F-单一事实源证据链.png`】**

- Isaac Sim 6.0.1 + OpenUSD：`PhysicsScene`、碰撞、刚体、质量、`FixedJoint`；抓取必须同时满足几何对齐和关节启用。
- `2.5D_OBB_SAT_SWEEP_V4`：normal 1,128,953 / recovery 1,248,809 / intervention 651,784 次候选对检查；障碍物穿透、禁碰、接触违规均为 0；最小车身净距 0.213986 / 0.213986 / 0.387376 m；水平放置误差 0。
- 测试：201 项 Python unittest（Windows 本地复验，1 项平台相关按预期跳过）+ 50 项 JavaScript 协议断言。
- 飞书现场任务 `T-DEMO-20260813-001`：单实例桥接只启动一次 runner，审计 0–19 连续，断点只回放已封存证据。

#### 2.3.5 产品形态：只读证据控制台

**【插入图 G：`fig-G-线上Demo界面四宫格.png`】**

- 四个页签：正常卸货 / 自动恢复 / 安全介入 / Fast-WAM 碗→盘。
- 首屏只有模式选择与 AgentOS 对话；发送任务后才展开视频、技能链、Fallback、审计。
- 输入与证据不一致时 fail-closed：切回可审计任务，不冒充新执行。
- 分屏视频 2560×1080：左侧 Isaac 作业，右侧同帧时钟的大脑/小脑/安全/审计摘要；不展示隐藏思维过程。
