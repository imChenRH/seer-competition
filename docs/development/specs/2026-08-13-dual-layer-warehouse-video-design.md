# 双层架构仓库演示视频设计

日期：2026-08-13
状态：已确认，直接实施

## 1. 目标

把现有可运行、可审计的 Isaac Sim 演示升级为可直接向企业展示的工业视频：

- 左半屏展示真实仿真画面，场景扩大为仓库内部，清楚呈现车辆行驶、货叉取货、举升、绕障和放置。
- 右半屏展示“大脑—小脑”双层架构如何分发、执行和验证任务。
- 所有右侧状态由同一轮仿真的 `events.jsonl` 推导，不使用预写动画冒充运行数据。
- 保留原始仿真视频、场景、事件和摘要；合成片是演示层，不替代原始证据。

视觉风格参考知乎文章《手把手教你使用 NVIDIA Isaac Sim 进行机器人仿真①》中的工业仿真视频：写实仓库、稳定镜头、真实光照与材质、少量高信息密度 UI，而不是卡通化或纯概念动画。

## 2. 透明性边界

右侧展示的是可审计的“决策摘要”，不是模型隐藏思维链：

- 可以展示：任务目标、VLA/AgentOS 输出的结构化意图、当前技能、技能参数、小脑观测、规则校验、安全门控、降级原因、恢复动作和审计序号。
- 不展示或伪造：模型逐 token 内部推理、不可验证的心理活动、与事件日志不一致的动画。
- 页面固定标注“DECISION SUMMARY · 来自可审计事件”。

## 3. 画面与资产

### 3.1 输出规格

- 分辨率：2560×1080。
- 帧率：与原始视频一致（正式证据当前为 8 fps）。
- 左右各 1280 像素宽。
- 左侧将 1280×720 原始画面置于垂直中央，上下用于场景名称、时间、技能、状态和证据标识。
- 右侧为动态工业控制面板。

每个正式场景目录同时包含：

- `simulation.mp4`：原始 Isaac Sim 视频。
- `presentation.mp4`：双栏演示成片。
- `events.jsonl`：结构化事件。
- `scene.usda`：场景快照。
- `summary.json`：运行与媒体元数据。

### 3.2 仓库场景

优先复用服务器已有的官方 SimReady Warehouse-01 资产，而不重复下载完整资产包：

- 仓库货架、托盘堆、墙体和地面使用 SimReady/USD 资产作为写实背景。
- 当前任务中的车辆、货叉、载荷与接触状态仍由既有仿真内核驱动。
- 场景底板扩大，并增加货架通道、装卸区域和内部障碍物，使画面体现“仓内作业”而不是小型测试台。
- 若官方资产不可用，自动回退到程序化仓库，不影响任务和证据生成。

不下载整套本地资产包的原因：服务器已有约 14 GB 的 Warehouse-01 资产，剩余磁盘约 29 GB；复用现有资产可避免重复占用和下载风险。

## 4. 右侧信息架构

右侧按四层组织：

1. 顶部：任务名称、场景、仿真时间、终态。
2. 大脑层：当前目标、结构化意图、技能分发、降级/恢复决策。
3. 小脑层：当前技能、物理观测、控制进度、验证结果。
4. 安全与审计：安全门控、人工介入状态、故障/恢复标记、最近事件和序号。

状态映射必须由纯函数生成，以便测试：

- 根据 `sim_time` 选择最后一个已发生事件。
- 从 `skill_started` / `skill_completed` 推导当前技能。
- 从 VLA、恢复、安全类事件推导大脑决策摘要。
- 从技能进度、物理观测与验证事件推导小脑状态。
- 人员侵入时安全门控优先于任务执行，并显示 `HUMAN_REQUIRED`。

## 5. 合成与网页播放

- Python/Pillow 负责生成逐帧透明信息层。
- FFmpeg 把原始视频、信息层和声音轨（若有）合成为 `presentation.mp4`。
- 合成脚本必须可重复执行，不提交临时 PNG 帧。
- 网页优先播放 `presentation.mp4`；若不存在则回退 `simulation.mp4`。
- API 和静态文件服务只允许播放 `summary.json` 声明的媒体文件，防止任意路径读取。
- MANIFEST 对原始片和演示片分别记录大小、SHA-256、分辨率、帧率和时长。

## 6. 验收标准

- 三个正式场景均生成可播放的 2560×1080 双栏视频。
- 左侧每个场景至少能看到车辆、货架/托盘、载荷和仓内通道；正常/恢复场景能看到取放闭环。
- 右侧技能、恢复、安全和终态与 `events.jsonl` 一致。
- 恢复场景展示抓取故障、重定位和继续执行；介入场景展示安全门控与人工接管。
- 原始视频仍可独立校验，合成片不会改变运行终态或物理时钟。
- 全部 Python 测试、JavaScript 协议测试、清单验证、FFprobe、网页实测通过。
- 文档明确区分“已验证”“部分验证”“待真机验证”。

## 7. 非目标

- 不声称已经接入仙工真机或 FastWAM 真机。
- 不把 UI 动画当作模型推理证据。
- 不为了画面效果篡改事件顺序、任务终态或仿真时间。
- 不在仓库中提交 NVIDIA 受许可约束的大型资产包；只提交由本项目生成的场景引用与视频证据。
