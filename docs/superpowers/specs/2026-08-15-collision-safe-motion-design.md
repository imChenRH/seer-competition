# SEER–HVLA 防穿模运动设计

日期：2026-08-15

## 结论

保留现有确定性时间线与事件契约，增加纯 Python 2.5D 几何守卫，不升级为完整轮胎/转向动力学。守卫同时处理 XY 平面的旋转包围盒和 Z 轴区间，在时间线生成、Isaac 每帧应用和正式证据摘要三个边界 fail-closed。

## 已复现根因

1. 叉车是 `kinematicEnabled=true`，`apply_frame()` 直接写入平移和偏航，PhysX 的 `CollisionAPI` 不会阻止运动学目标穿过静态碰撞体。
2. 退出集装箱到传送带的单段轨迹同时插值位置与角度；即使终点车身净距为 0.6 m，中间旋转扫掠仍有 10 帧与传送带重叠，发生在 normal 的 49.125–50.25 s。
3. 栈板目标根高度为 0.55 m，而滚筒顶面为 0.78 m，最终垂直穿透约 0.23 m。
4. 传送带使用一个实心底座，货叉进入放置位时会进入底座体积。
5. 旧测试只检查静态 Prim 是否带 CollisionAPI 和终点标量净距，没有检查动态包围盒、相邻帧扫掠或支撑面高度。

## 几何模型

- 叉车车身：长 2.20 m、宽 1.50 m 的 OBB，Z 区间覆盖车轮以上的车体。
- 两根货叉：使用实际局部中心、尺寸、门架高度和叉车偏航生成两个 OBB。
- 活动栈板：水平包围盒 1.15×1.28 m；Z 下界来自栈板最低构件。
- 静态禁入体：集装箱侧墙/后墙/门柱、月台、传送带车身禁入包络、货架和可见障碍物。
- 地面、集装箱地板属于允许支撑面，不作为车身禁入体。

XY 使用分离轴定理，Z 使用闭区间重叠。对车身与静态设施额外膨胀 0.05 m；接触即视为违反净距，允许接触对除外。

## 扫掠规则

每个相邻姿态之间按以下上限细分：

- 平移步长不大于 0.025 m。
- 偏航步长不大于 0.5°。
- 使用最短角度插值。

任一子步出现非法重叠，时间线构建立即抛出带动态体、静态体、帧号和阶段的异常；Isaac runner 在写入下一帧前再次验证，不能继续渲染或产生 `COMPLETED`。

## 路径与传送带

传送带对接拆成：离开集装箱、到达传送带外侧预对准点、在安全区完成偏航、保持固定偏航直线靠近。预对准点使用传送带局部坐标，确保整个旋转扫掠不接触传送带。

传送带不再使用实心底座，改为侧梁、支腿和三列窄滚筒支撑带。支撑带对齐栈板三根 runner，货叉中心 `y=±0.32 m` 位于支撑带间的开放通道。

## 垂直接触与白名单

- 栈板在集装箱内：底面高于地板顶面 0.005 m。
- 插叉时：货叉顶面与栈板 deck 底面一致，允许货叉进入两个开放叉孔。
- 搬运时：活动栈板相对门架高度保持不变，不得瞬间跳变。
- 放置时：栈板底面位于滚筒顶面上方 0.005 m；水平中心误差不超过 0.02 m。
- 释放前：叉车线速度不超过 0.02 m/s、倾角回到 0°、栈板支撑误差不超过 0.01 m。
- 允许接触只有车轮/地面、栈板/地板、货叉/叉孔、栈板 runner/传送带支撑带；其他动态—静态重叠全部禁止。

绿色目标标记移动到 `/World/Visuals`，关闭碰撞，不参与物理合同。

## 证据与验收

正式摘要增加碰撞守卫版本、扫掠检查次数、最小车身净距、最大允许接触误差和非法碰撞数。验收条件：

1. normal、recovery、intervention 全部帧及相邻帧扫掠的非法碰撞数为 0。
2. 车身与静态设施最小净距不小于 0.05 m。
3. 栈板最终支撑误差不超过 0.01 m，不出现位置跳变。
4. intervention 在可见障碍物前停车或调整观察位，不得进入障碍物包围盒。
5. 三条 Isaac 原始片和分屏片重新生成，抽帧覆盖进箱、插叉、转向、对接、释放和安全停车。
6. 任何守卫失败不得生成终态成功事件或正式 Manifest。

## 边界

该设计证明的是确定性轨迹满足简化几何和接触规则，不证明真实轮胎、转向、制动、摩擦或载荷动力学。完整车辆动力学仍需要企业模型和标定参数。
