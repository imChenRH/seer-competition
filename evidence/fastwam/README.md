# Fast-WAM 独立验证证据

`validation.log` 是 2026-08-13 AutoDL 单批推理日志的脱敏摘录。原始日志 SHA-256：

```text
96aec2760b678802f59b099807e3696b46940846238e9450e71e473d7dff2394
```

该证据只证明本地 checkpoint 能加载到 CUDA 并返回形状 `[1, 7]` 的动作张量；日志中的 0.86 s 是未编译首次单次调用，不是稳定基准。日志同时保留了依赖、配置与 tokenizer 告警，因此不能据此宣称 Fast-WAM 已达到论文 190 ms、已控制叉车或已适配叉车场景。
