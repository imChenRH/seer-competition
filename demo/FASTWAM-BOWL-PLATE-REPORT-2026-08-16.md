# Fast-WAM 黑碗放入盘子 Demo 交付报告

## 结论

Demo 已切换到官方 LIBERO `libero_goal` task 8：`put_the_bowl_on_the_plate`。AgentOS 接收“把黑色碗放入盘子”，Fast-WAM 使用两个真实仿真相机观测生成全部 7D 动作，MuJoCo 执行动作，终态仍由原版 `env.check_success()` 判定；没有规则控制器补动作，也没有修改成功谓词。

正式运行 `fastwam-bowl-plate-20260816-v2-r1` 的五个固定初态全部通过官方成功谓词。五次均在 300 步预算内完成，实际执行 77–84 步。页面展示第 0 次轨迹，同时保留并哈希五次尝试的视频、动作和物理状态。5/5 只描述这五个固定初态，不代表通用成功率或完整官方基准复现。

## 关键修正

1. 删除苹果、黄盘自定义资产和 BDDL 覆盖，回到 checkpoint 训练分布内的官方黑碗与盘子任务。
2. 保持官方 300 步预算、五个固定初态和原版成功谓词，不再用 600 步语义迁移预算掩盖任务错配。
3. checkpoint 在 CPU 装载后一次迁移至 CUDA，任务文本上下文预计算后释放编码器，避免 24 GB 显存峰值溢出。
4. 事件投影只使用实测碗举升、盘心误差、夹爪状态和官方成功谓词；帧号单调，不展示隐藏思维过程。
5. Fast-WAM 复用前三个场景的公共证据区和分屏渲染器：相同 TASK、BRAIN、CEREBELLUM、SAFETY、AUDIT 卡片，相同运行/恢复/完成/人工介入色彩语义。
6. 五组原始视频、动作、状态以及主轨迹和同步分屏片全部由顶层 Manifest 记录 SHA-256。

## 分层架构展示

- 大脑层：中文任务、规范化 policy prompt、技能顺序和审计事件。
- 小脑层：Fast-WAM 7D 动作、动作队列/新策略调用和实测调用延迟。
- 物理层：MuJoCo 相机画面、碗举升、盘心误差、夹爪状态和官方成功谓词。
- 证据层：同一视频帧时钟、连续 JSONL、五次固定初态结果和 Manifest 哈希。

`presentation.mp4` 为 2560×1080、20 fps、85 帧。左半屏是 1280×720 MuJoCo 操作，右半屏使用与三个叉车场景相同的结构化决策卡；运行和完成分别使用蓝、绿主题。

## 声明边界

- 5/5 只描述随附五个固定初态，不能外推为模型或系统的通用成功率。
- 本次运行使用官方任务和官方成功谓词，但不是覆盖完整官方评测集的基准复现。
- 它不控制叉车，不证明实机迁移、生产安全、ROS 2 或仙工设备接入。
