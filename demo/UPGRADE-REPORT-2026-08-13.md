# SEER–HVLA Demo 四项升级交付报告

日期：2026-08-13

依据：《给 Codex 的 SEER–HVLA Demo 升级提示词》与仓库补充规格。

## 总体结论

继续采用“局部重构”，不推倒已有事件契约、九技能状态机、飞书桥接与证据体系。四项升级已达到企业交流 Demo 的可运行门槛，但规控物理化按任务书允许的路径降级为：

> 确定性运动目标 + 显式、可审计的 `UsdPhysics.FixedJoint` 叉取/释放状态。

因此不能宣称完成了轮式底盘、门架和货叉的标定 PhysX 闭环，也不能外推为真实叉车性能。

## 关键真实性措施

1. `events.jsonl` 继续是唯一事实源；网页和右侧决策摘要不生成独立成功数字。
2. 叉取状态同时要求：托盘相对几何满足阈值、`physics:jointEnabled=true`。仅几何重合会 fail-closed。
3. 三段分屏视频与原始视频具有相同 fps、帧数、时长；右侧每帧按 `frame_index / fps` 投影事件。
4. 右侧展示的是任务目标、结构化意图、技能/Fallback、安全门和审计事件，不展示模型隐藏思维过程。
5. 网页输入若与随附任务证据不一致，不会伪造新执行；页面会提示并恢复为可审计指令。
6. Fast-WAM 页只解析完成标记齐全的本地脱敏日志，并同时显示不可外推边界。
7. 叉车偏航角使用 Z 轴角度并写入场景时间采样；集装箱约 `+8°`、传送带约 `-6°`，路径、相机偏差和载荷相对位置都在设施局部坐标系计算。
8. 设施布局在生成前执行间距合同：集装箱、月台、传送带不共线正对，车辆中心线与静态设施边界保留至少 `0.6 m` 演示净距。

## 如何展示

```bash
./scripts/run_demo.sh serve demo/evidence 8765
```

打开 `http://127.0.0.1:8765/`：

1. 页面初始只显示四个模式和 AgentOS 对话；在“正常执行”发送已预填任务后，观察技能分发区与分屏片同时展开。
2. 切换“自动恢复”，讲解 `FB-F01`。
3. 切换“安全介入”，强调 `HUMAN_REQUIRED` 而非“失败后完成”。
4. 切换“Fast-WAM 验证”，只证明 `[1,7]` 单批输出和 0.86 s 首次单次调用，不宣称叉车或机械臂闭环。
