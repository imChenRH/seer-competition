# 仍需企业或人工提供的输入

以下事项不能由 Demo 代码诚实替代；它们是下一阶段进入实机或生产验证的明确门槛。

| 输入 | 当前为何不能自动补齐 | 需要的交付物 |
|---|---|---|
| 仙工叉车/底盘模型 | 当前叉车为程序化演示几何体 | USD、URDF 或 CAD；质量、尺寸、关节限位与载荷曲线 |
| 运动与状态接口 | 不能凭猜测对接 SRC-5000 | SDK/API/ROS 2 接口、坐标系、频率、超时、错误码、日志格式 |
| 安全链路 | 仿真安全门不是安全认证 | 急停、安全 PLC、区域防护、操作员确认与企业验收标准 |
| 标定物理参数 | 当前无真实轮胎/制动/载荷标定 | 轮胎、摩擦、制动距离、门架与货叉动力学、地面材料参数 |
| Fast-WAM 叉车数据 | 现有 checkpoint 未对叉车任务后训练 | 脱敏图像、状态、操作、失败样本与动作定义；后训练和离线评测方案 |
| 可用网络与部署环境 | AutoDL 当前不具备所需 UDP/WebRTC 条件 | 企业内网或具备 UDP 映射的 GPU 主机、端口策略与访问控制 |
| 现场签署证据 | 本地哈希和操作员回执不是平台签名 | 企业侧日志导出、签名/可信时间戳、验收人和版本冻结记录 |

在上述输入缺失时，系统继续以“确定性运动目标 + 显式物理挂接 + 结构化审计”的演示模式运行，并禁止把结果外推为实机闭环或生产安全结论。
